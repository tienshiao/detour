The [automation endpoint](./automation-endpoint.md)'s XCTest suites, all in
`DetourTests` (the `DetourTests` scheme).[^test-dir] Tests start their own
endpoint: the test host never listens on its own. Suites that need an
inactive host (a sidebar row's select, an Archived Tabs, palette and
Settings list row, the two TASK-228.10 tests) skip when the host is the
active app.

# Not covered

Not covered by tests: the re-check of the gates after the glide, before a
window is made key (it needs a gate that flips mid-glide), and the guard
against making a window on another Space key (the host cannot put a window
on another Space); both are left to code order and review.[^task-228-10]
