Externally connectable page

A web page, not an extension page. API Explorer lists http://127.0.0.1/* and http://localhost/* in externally_connectable, so served from either this page gets chrome.runtime.sendMessage / connect. Served from anywhere else (try http://[::1]:PORT/) it gets no chrome.runtime. Paste the id shown in the popup's "Externally Connectable" section (or pass ?id=…).
