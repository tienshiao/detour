# What's New in Detour 0.4.3

- **Closed windows stay closed** — a link opened from another app, or a Quarantine window's Open in, could bring back a browser window you had closed. Its sidebar no longer kept up: tabs kept the address they opened with, and a tab you closed left its row behind. Detour now only uses windows that are open.
- **Memory** — a closed window stayed in memory if it had a video in picture in picture or a docked Web Inspector. Closed windows are now freed.
