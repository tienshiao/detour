# What's New in Detour 0.4.2

- **Extensions per profile** — an extension you install is turned on only in the profile you installed it from, and a new profile starts with no extensions, so a profile you keep for banking stays free of them. Settings > Extensions shows where each extension is on and can turn it on in all your profiles at once. Extensions you already have stay on where they are.
- **User agent** — sites no longer see your exact macOS version. With Identify as Safari in Settings > Profiles, Detour sends exactly what Safari sends; the default Detour setting adds only "Detour/" and the major version. Extensions' background pages and Detour's own requests, such as site icons and search suggestions, send Safari's user agent too.
- **Settings** — a custom user agent can no longer be left empty, and the notes on extensions allowed in Private windows now say their data is cleared when the last Private window closes.
