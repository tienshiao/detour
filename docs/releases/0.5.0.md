# What's New in Detour 0.5.0

- **Keyboard shortcuts** — Settings › Shortcuts lets you give any menu command a shortcut, or change the one it has. Detour warns about a shortcut that is already taken, including one that only differs by Shift on your keyboard layout, and Restore Defaults puts everything back.
- **Commands in the command palette** — type a command's name in the palette to run it, or type > to list only commands. A command that needs a space, a tab or an extension asks for it right in the field.
- **Jump to a space** — Control-1 through Control-9 switch to the first nine spaces.
- **Settings** — every pane now uses the grouped rows of System Settings, with switches instead of checkboxes, and VoiceOver reads each setting once.
- **Clean links** — Copy URL and Share… leave out tracking parameters, also those listed in AdGuard's URL Tracking filter, which you can turn off under Content Blocking.
- **Content blocking** — a rule with an option Detour doesn't support is now skipped rather than blocking the whole site, changing a list applies to tabs in the background too, large lists block from every part, and a list being updated keeps blocking until the new one is ready.
- **YouTube and video stay working** — Detour now restarts its graphics process as soon as a page loses its graphics context or the process nears its limit, even while you are using the Mac, so long sessions no longer end with YouTube refusing to play.
- **Memory** — when macOS runs low on memory, Detour puts hidden tabs to sleep sooner, and tabs hidden for 15 minutes give back the memory their cached back and forward pages hold.
- **Back to the opener** — swiping back or pressing Command-[ on a tab opened from another tab closes it and returns you to the tab that opened it, and Reopen Closed Tab keeps that link.
- **Quick Detour** — the launcher finds pages from every profile's history, each labeled with its profile and the space you last visited it in, and opens it there. It now always comes to the front.
- **Local servers** — type localhost, a port or 127.0.0.1 in the command palette or Quick Detour to see the web servers running on your Mac, with the folder each one serves.
- **Undo** — Command-Z undoes your typing in a page, in a page's prompt and sign-in sheets, in Settings and in extension popups, rather than reopening a closed tab.
- **Links** — Open Link in New Tab and Open Link in New Window follow your Link Routes, and in a Private window they stay Private.
- **Automation** — the Automation section in Settings › General can let AI agents, such as Claude Code, drive and inspect Detour through a local MCP server. It is off until you turn it on, each agent asks for your approval once, and Private windows stay closed to agents unless you allow them.
- **1Password** — Detour looks for native messaging hosts in its own folder first, so a broken entry left by Chrome no longer stops 1Password connecting.
