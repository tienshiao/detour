# What's New in Detour 0.3.1

- **Pop-up windows** — a window a page opens is now a real pop-up that the page can talk to, so sign-in pop-ups report back to the site and links that open a new window no longer leave an empty tab. A page can close its own pop-up again.
- **Fewer frozen pages** — a page stuck behind a hung graphics or web process is recovered instead of staying frozen, and a page that is already showing (such as a playing video) is no longer replaced by an error page when its connection times out.
- **Keyboard focus** — clicking a tab in the sidebar leaves typing to the page, and a page that moves to another window takes the keyboard straight away. Cmd+L then Return opens the address shown instead of a history entry.
- **Sidebar and tab switching** — a sidebar revealed by hovering hides reliably when the pointer leaves. The Control+Tab switcher shows a tab's Peek and no longer passes its keys on to the page.
- **Private windows** — a Private window's downloads appear only in that window's download list, and the list is forgotten when the window closes; the files themselves stay where they were saved. Closing the window while a download is still running asks first. A normal window's command palette no longer suggests tabs from Private windows.
- **Content blocker** — very large filter lists now apply in full, including their exceptions.
- **Extensions** — an extension installed from a .crx file or the Chrome Web Store must be properly signed, at install and at every update. Extensions only see the history of the profile they run in.
- **Reliability** — data: URLs open in the tab, and a problem saving one part of your session no longer loses the rest.
