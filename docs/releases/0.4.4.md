# What's New in Detour 0.4.4

- **Import from Arc** — File > Import from Arc… brings your Arc spaces, pinned tabs and folders, favorites, unpinned tabs and the last 90 days of history into Detour, from Arc on this Mac or from the file Arc's Export Data saves. Each Arc profile becomes a Detour profile, spaces keep their names, emoji and colors, and importing again adds nothing twice. If Arc is on this Mac, Detour offers once to bring everything over. Logins, passwords and extensions stay in Arc, which stops working on December 22, 2026.
- **Spaces** — the + at the bottom of the sidebar and Edit Space… open the space editor right in the sidebar: a name, a color, an icon and a profile, with the sidebar showing the color while you choose. Undo takes back a new or edited space.
- **Quick Detour** — a Back button next to the window buttons, a click anywhere on the address goes somewhere else, and the address fills as the page loads.
- **Downloads** — a download's icon flies from where you clicked into the Downloads button. Download Linked File and Download Image in a link's or image's menu work again.
- **Buttons** — a dimmed button no longer lights up when the pointer is over it.
